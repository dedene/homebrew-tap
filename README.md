# Homebrew Tap

Personal Homebrew tap for [dedene](https://github.com/dedene) packages.

## Installation

```bash
brew tap dedene/tap
```

## Formulas

| Formula | Description |
|---------|-------------|
| [claw-wrap](https://github.com/dedene/claw-wrap) | Credential proxy for CLI tools — secrets never enter the sandbox |
| [delijn](https://github.com/dedene/delijn-cli) | CLI for De Lijn — Flemish public transport departures, stops, and routes |
| [frontcli](https://github.com/dedene/frontapp-cli) | CLI for Front.app — manage conversations, messages, contacts, and more |
| [harvestcli](https://github.com/dedene/harvest-cli) | Harvest time tracking CLI |
| [irail](https://github.com/dedene/irail-cli) | CLI for Belgian railway (NMBS/SNCB) schedules |
| [lametric](https://github.com/dedene/lametric-cli) | CLI for LaMetric devices — control your device from the command line |
| [ponto-cli](https://github.com/dedene/ponto-cli) | CLI for Ponto banking API — manage accounts, transactions, and syncs |
| [raindrop-cli](https://github.com/dedene/raindrop-cli) | CLI for Raindrop.io — manage bookmarks, collections, and tags |
| [rr](https://github.com/dedene/realtime-register-cli) | CLI for RealtimeRegister — manage domains via the registrar API |
| [strawpoll](https://github.com/dedene/strawpoll-cli) | CLI for StrawPoll — create and manage polls from the command line |

## Usage

```bash
brew install dedene/tap/claw-wrap
brew install dedene/tap/delijn
brew install dedene/tap/frontcli
brew install dedene/tap/harvestcli
brew install dedene/tap/irail
brew install dedene/tap/lametric
brew install dedene/tap/ponto-cli
brew install dedene/tap/raindrop-cli
brew install dedene/tap/rr
brew install dedene/tap/strawpoll
```
