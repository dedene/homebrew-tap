# Homebrew Tap

Personal Homebrew tap for [dedene](https://github.com/dedene) packages.

## Installation

```bash
brew tap dedene/tap
```

## Formulas

| Formula | Description | Version |
|---------|-------------|---------|
| [claw-wrap](https://github.com/dedene/claw-wrap) | Credential proxy for CLI tools — secrets never enter the sandbox | 0.1.1 |
| [delijn](https://github.com/dedene/delijn-cli) | CLI for De Lijn — Flemish public transport departures, stops, and routes | 0.1.0 |
| [frontcli](https://github.com/dedene/frontapp-cli) | CLI for Front.app — manage conversations, messages, contacts, and more | 0.1.4 |
| [harvestcli](https://github.com/dedene/harvest-cli) | Harvest time tracking CLI | 0.1.0 |
| [irail](https://github.com/dedene/irail-cli) | CLI for Belgian railway (NMBS/SNCB) schedules | 0.1.0 |
| [ponto-cli](https://github.com/dedene/ponto-cli) | CLI for Ponto banking API — manage accounts, transactions, and syncs | 0.1.0 |
| [raindrop-cli](https://github.com/dedene/raindrop-cli) | CLI for Raindrop.io — manage bookmarks, collections, and tags | 0.1.1 |
| [strawpoll](https://github.com/dedene/strawpoll-cli) | CLI for StrawPoll — create and manage polls from the command line | 0.1.3 |

> **Note:** `claw-wrap` is Linux-only.

## Usage

```bash
brew install dedene/tap/claw-wrap
brew install dedene/tap/delijn
brew install dedene/tap/frontcli
brew install dedene/tap/harvestcli
brew install dedene/tap/irail
brew install dedene/tap/ponto-cli
brew install dedene/tap/raindrop-cli
brew install dedene/tap/strawpoll
```
