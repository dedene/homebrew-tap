# Homebrew Tap

Personal Homebrew tap for [dedene](https://github.com/dedene) packages.

## Installation

```bash
brew tap dedene/tap
```

## Packages

| Formula | Description |
|---------|-------------|
| [frontcli](https://github.com/dedene/frontapp-cli) | CLI for Front.app |

## Usage

```bash
# Install frontcli
brew install dedene/tap/frontcli
```
